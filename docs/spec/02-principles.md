## 2. Principles (non-negotiable)

These override every other section. Each is phrased so a reviewer can check a change against it.

- **P1 — A rule is a refusal or an automatic state change.** It is never only a prompt, and never only a notification. Prompts may explain rules; they never are the rule. Quality and style are not rules: they are measured, shown and fed back, never refused.
- **P2 — Rules point both ways.** A floor that fires when a project under-reaches is as legitimate and as server-enforced as a ceiling that refuses over-reach. Examples of floors: no visible output, an idle seat, a spinning project, a stalled board. The rebuild ships floors, not only brakes.
- **P3 — Agents act only through the agent API.** Each run gets a credential scoped to one run, one agent and one project. Agents never touch storage, never hold another project's data, and never hold provider keys: model calls go through the platform's model gateway. The single exception is a subscription harness that cannot use the gateway (LLM-8), which is labelled as a weaker boundary.
- **P4 — Everything an agent reads is untrusted input.** That includes web pages, uploads, chat messages, email and other agents' output. Agent-authored text that reaches a human or a human's AI client is wrapped and labelled as untrusted.
- **P5 — Nobody grades their own work.** No agent marks its own work done or gives the verdict on its team's work, and that includes the CEO. Completion requires a platform-run check, outside evidence the platform verifies, or a reviewer who is not the author. The one exception: a solo project that has turned independent read off may close observable-test tasks as **self-reported**, labelled as such everywhere (WRK-6, WRK-15). Command tests always need the platform check (INV-2).
- **P6 — Silence is never consent to act.** At its deadline an item resolves to its declared default. No default may spend, grant a permission, widen scope, or cut scope the chairman wrote. Defaults may only close bookkeeping, such as completing a delivered project or closing a green review.
- **P7 — The chairman owns the goalposts.** The goal, standing orders, closed decisions, budget, quality and chairman-authored scope are changed only by the chairman, at every authority setting. Every chairman change carries a written reason and is disclosed to the CEO.
- **P8 — Idle costs nothing.** Whether an agent has work is decided by a query before any model call. A project with nothing to do spends 0 tokens. Reports, briefs, agendas and reviews are built by the platform from the record, at 0 tokens.
- **P9 — Every token is metered,** including failed, killed and reaped runs. Metering happens at the model gateway, not on the harness's word.
- **P10 — Every rule ships with an attack.** Each enforced rule has an automated test that tries to break it the way an agent would (forged or foreign tokens, wrong roles, rephrased requests) through the public API.
- **P11 — One concept, one implementation, every surface.** Each operation is implemented once and exposed to the chat, app panels, API, CLI, MCP and (where relevant) Slack and the agent API. A concept is not done until it appears on every surface it belongs to, or the operation catalog says why not.
- **P12 — Honest about limits.** The product states plainly what it does not contain (such as network egress), and labels every substitution, such as "Best quality running on a balanced model: no frontier model on this key".
- **P13 — Facts belong in fields, not prose.** Dates, budgets, thresholds and authority live in structured, enforced settings. A number buried in a goal paragraph cannot be enforced, yet agents will still treat it as binding, so the system steers it into a field.
- **P14 — Speed is a feature.** Ready work never waits on a clock. The only throttles are the budget, concurrency, provider limits and runaway guards. Time is measured and attributed: working, waiting on the chairman, waiting on a limit, waiting on a provider.
- **P15 — Conversation is not command.** A chat message is talk. An agent changes state on the chairman's words only through a directive: `/do`, or an action card the chairman accepted. Within its delegated authority and its own plan, it acts without asking.
- **P16 — The chairman says it once.** Standing orders, closed decisions, corrections and marked examples are stored exactly (not summarised) and placed in every run of every agent they concern.
- **P17 — Never silent.** Every chairman message gets an agent reply, or a platform status naming the reason and when a reply will come. Every hold on work is visible with the time it lifts.
- **P18 — Plain words.** Everything shown to the chairman leads with the answer or the ask, in plain language. Internals (probabilities, ids, traces) sit behind a "details" fold.
