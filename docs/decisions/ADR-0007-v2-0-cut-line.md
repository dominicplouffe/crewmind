# ADR-0007: v2.0 is phases 0–7

- **Status:** Accepted (21 Nov 2026, owner: Dominic)
- **Spec:** docs/PLAN.md, section 13

## Context

v1 grew to about 87,000 lines in seven weeks and failed on structure.

## Decision

Ship phases 0–7 as v2.0. Phase 8 (project email, browser, OpenTelemetry, Agent Skills, A2A, Slack, extra harnesses, host-jail, SSO) follows. Web search moves into phase 2.

## Consequences

The spec keeps phase 8 requirements so v2.0 leaves room for them.
