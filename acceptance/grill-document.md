Hollin Valley bird guide: working brief

We want a printed field guide to the birds of the Hollin Valley for people who walk there.

The guide covers the forty commonest birds of the valley. Each bird gets one page with a plate, a range note and a season note.

The guide must be finished in time for the spring walking season. Because the print shop is booked, the guide covers the sixty commonest birds so that the print run is worth its cost.

Every entry must be easy to use. A beginner should be able to name a bird quickly.

For scale: a typical entry might run to about 250 words, as in the sample entry for the wren that the editor wrote last year.

Every plate is a drawing. Photographs are not used anywhere in the guide. Where a photograph shows a bird better than a drawing can, use the photograph.

The guide should make walkers love the valley more than they did before.

The chairman will answer questions about the valley and approve the final proof.
